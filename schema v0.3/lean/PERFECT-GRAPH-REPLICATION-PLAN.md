# Constructive route to weighted perfect-graph duality

The remaining target is the actual proposition in `ExternalPerfectGraphFoundation`: every finite `IsPerfect G` has `maxWeightIndependent G w = fractionalCliqueCoverValue G w` for all nonnegative real w. The existing certificate is a specification, not a proved foundation and not an additional premise for the intended endpoint.

The first module, `PerfectGraphColorClass.lean`, handles the key color-class deletion step. Given a k-coloring C and a vertex x in no k-clique, every k-clique contains a vertex of color C(x) distinct from x. Thus the induced graph on `{v | v = x or C(v) != C(x)}` has clique number below k. `IsPerfect G` supplies its `(k-1)`-coloring. A separate constructor extends a coloring across any independent block using one fresh color. These are actual finite combinatorial statements and colorings; they do not define replication or duality to be true.

Next, define **true-twin replication** on `Option V`: `some v` represents each old vertex, `none` is the new copy of x, the new copy is adjacent to x and exactly x's old neighbors, and old adjacency is unchanged. Prove chi equals omega for the replicated graph in two cases. If x belongs to a maximum k-clique, use one extra color and the replicated `(k+1)`-clique. Otherwise use the deletion lemma above: the new vertex together with the removed same-color vertices is independent; the retained old vertices admit `(k-1)` colors. Induced subgraphs with zero or one copy reduce to old induced graphs; those with both copies reduce to replication of an old induced graph. This supplies preservation of the actual hereditary `IsPerfect` definition. Isomorphism and finite-cardinality transport are explicit obligations.

**Replication alone does not finish the weighted target.** The integer-weight route also needs weak perfectness, or equivalently the unweighted minimum-clique-cover/maximum-independent-set equality for perfect graphs. One replication-based construction is to count, for each vertex, how often it appears among all maximum independent sets, and replace it by that many mutually adjacent true twins. Perfection and counting force a clique meeting every maximum independent set. Removing this clique lowers alpha; induction constructs an alpha-sized clique cover. Applying the same reasoning hereditarily gives perfection of the complement. This is a real combinatorial proof stage, not a continuity or bookkeeping step.

For nonnegative integer weights, replace each vertex of the complement by a clique of its prescribed size, deleting zero-weight vertices. Repeated true-twin replication preserves perfection. Its chromatic number equals its clique number, which is the weighted independent-set value of the original graph. Each color class projects to a clique of the original graph and covers each vertex the required number of times. Counting color classes yields an explicit integral cover attaining the weighted independent-set value; the already proved weak-duality inequality provides the opposite inequality.

For rational weights, choose a positive common denominator. Prove finite-maximum homogeneity and transport cover coefficients by reciprocal scaling. This yields equality with no real LP-duality hypothesis. For real nonnegative weights, prove continuity of the two finite optimization values. Alpha is a finite maximum of linear functions. The fractional cover value is Lipschitz in the l1 distance on weights: take an attained minimizing cover and add nonnegative singleton weights sufficient to cover coordinate increases, then reverse the roles. The existing `fractionalCliqueCoverValue_attained` supplies the minimizers. Approximate by nonnegative rational vectors and take limits. This avoids silently assuming continuity of an infimum.
