## 到 query 容量上界还差什么

三个参数必须分开：目标论文的量子比特数记 q，矩阵阶数记 N=2^q，反对易生成元数记 r。Hurwitz 结尾的 p 是复合问题第一因子的变量数，不可直接替换为 r。

原刊 316（PDF 9）确实给出按 N 模 4 区分的 p 上界。要从这一段用于目标分支，至少需要：

1. 在广义复合问题中证明标准化后得到 p−1 个矩阵的对应，因此建立 r=p−1 的适用条件。该转换不能仅凭两条对数不等式猜测。
2. 区分普通转置斜对称条件 Bᵀ=−B、平方 B²=−I，与 Pauli 的 Hermitian/平方为 I 条件。乘以复数 i 可以改变平方，不能自动赋予普通转置斜对称性。
3. 对一般可逆反对易族，仍需 Shapiro/Robert 所指的更一般独立性论证或另一个逐前提对齐的推广。不得用本篇受限系统替代所需一般定理。
4. 最后才将一般矩阵阶数 N 的上界转为 q 比特的 2q+1，并连接目标论文的容量命题。现有未编译的 F₂/Pauli 候选证明不自动构成历史来源链已经对齐的证据。

因此 c24–c26 的公式阅读本身不能关闭外部依赖。它们是有用的历史线索；最早出处及一般化桥接仍未完成。
