01 / The problem

Four questions about trust

Source fidelity
What did the paper actually state?
Mathematical correctness
Does the conclusion follow from the encoded assumptions?The central question in this case study
Computational reproducibility
Can the reported numerical result be reproduced?
Physical meaning
Does the formal object represent the intended physics?

A proof check answers one question. The other questions need their own evidence.

保留四条独立轴，今天重点是数学推导及其依赖，同时用原文锚点帮助追溯。我们选定的定理没有需要复现的数值结果；形式化也不自动解决物理语义对齐。过渡：先分清系统里谁生成内容、谁执行检查。

02 / What the tools do

The agent and its tools

The agent runs a loop: call the model, execute permitted actions,
return the results, then continue or stop.

Skill
A written procedure supplied to guide the work.
API / MCP
Interfaces for model and tool calls. MCP provides a common tool protocol.
Tools
Retrieve sources, save records, run a compiler or invoke a proof checker.
Host
Enforce the configured rules and save what actually happened.

Tool access makes checks possible. Recorded tool results show which checks actually ran.

API、MCP和skill只保留理解工作流所需的职责，不做名词巡礼。MCP不是数学验证器，skill被加载也不等于已执行。这里的host指执行环境和控制程序。过渡：结构检查与证明检查的保证不同。

03 / Building a research record

A paper with a persistent research record

An agent can help maintain the work around a paper.
The saved record makes that work available to the next reader.

Which statement?
The exact claim, its assumptions and a location in the frozen source.
What supports it?
The premises used together and the external results it imports.
What is established?
The checks already recorded and the obligations still unresolved.

The useful output is a claim with an inspectable history.

我们可以设想由agent持续维护论文周围的研究工作：回答具体声明在哪里、需要哪些前提、还有哪些问题没有解决。要让这些回答可追溯，就必须把研究记录保存下来。构建这份记录时，需要朝两个方向工作。

03 / Building a research record

Trace backwards, check forwards

Start from the desired result

Trace its dependencies

Find the definitions and premises the argument uses.

Follow imported results to their sources and record unresolved gaps.

Start from the available premises

Check each inference

State the assumptions explicitly and submit the formal proof.

Carry the conditions forward when composing the final result.

A missing premise becomes a concrete research task.

从目标出发向后追溯，我们逐渐找到它需要的定义、引理和外部结果。从已具备的前提出发向前检查，我们判断每一步是否成立，以及最终能否接到目标上。追溯得到的缺口，决定下一步要阅读或证明什么。

03 / Building a research record

The boundary of formalization

A formal statement makes the objects and assumptions explicit.
A proof term gives the checker a derivation to inspect.

Assumptions ⊢ conclusion

Autoformalization

Interpretation

Source alignment and the applicability of the assumptions still require evidence.

04 / One paper, one theorem

The result we want to inspect

Case study: arXiv:2607.26154v1

RoMM(ρ) = max { 1, maxQ ∑P∈Q |tr(Pρ)| }

What it states
A closed form for reduced robustness of magic using cliques Q of GM.
Stated assumptions
M has no active dependencies. The graph GM is perfect.
Our question
Which definitions, imported results and local steps support this equality?

The equality is the destination. Its supporting chain is the object of this talk.

不要求听众先熟悉magic资源论。RoM是robustness of magic；M是选定的Pauli可观测量集合；G_M的clique是公式中的Q。具体物理意义可问答展开，今天追索它作为数学结论依赖哪些假设。出处为原HTML的MathClaim记录和节点contract。

04 / One paper, one theorem

One sentence becomes an explicit claim

Quantifiers
n, m and M are implicit in the source statement. ρ is explicit.
Additional assumption
m ≥ 1 appears in the proof, rather than in the theorem statement.
Convention
The empty clique is allowed and contributes zero.
Provenance
The record identifies the source and carries content fingerprints.

Source record: math-claim-ir / closed-form-equality

Making an assumption explicit gives the reviewer something specific to examine.

这份MathClaim记录明确列出了原句中隐含的量词，并将m≥1定位到证明而不是定理陈述中。这样的展开为审阅提供了具体对象。内容指纹用于版本追踪，不能证明数学正确。登记表中的closed-form-equality和后面人工图里的closed-form-rom是对应同一目标的不同记录。

04 / One paper, one theorem

A small proof with a recorded check

A separate local example: the coefficient lower bound

∑i xi = 1   ⇒   1 ≤ ∑i |xi|

The model returned

A structured proof using normalized_l1, plus a pending obligation to elaborate the terms.

The host recorded

The submitted terms elaborated and the kernel accepted the generated declaration.

result.kernel_checked = true

Finite index type, real coefficients. Nonnegativity is not required.
The supplied declaration set had two entries, including the lemma used.

This checks the coefficient bound. The paper’s target theorem remains a separate task.

现在看一个较小的局部命题：实系数之和为1，则绝对值之和至少为1。它与刚才的RoM闭式定理是不同的证明任务。模型先返回证明，并注明宿主检查尚未进行；随后ledger记录宿主提交和内核接受的结果。两个时间点的状态共同组成一条可追溯记录。这次运行提供的声明集合只有两条，其中一条就是所用引理，因此这个案例展示局部流程贯通，尚未展示模型在大规模库中自行检索适用定理的能力。
