# 教学样例，不是真实论文运行

`workflow.json` 只演示一个形式化交接片段：生成尝试交付后，独立检查任务因为执行环境缺失而受阻；Reader 解释现状。它不是从论文提取到科学准入的完整实验。

- 根字段 `data_class=SYNTHETIC` 标记整套样例。
- 其中业务记录引用使用 `fixture:` 编号和占位内容指纹。它们用于测试格式和版本绑定，不代表真实业务记录已存在；工作单检查不会解析这些引用的真实字节。
- 结构依赖顺序不等于就绪队列。检查任务返回 BLOCKED，任何要求其成功证据的下游任务都不能被放行。
- Reader 附件是真实存在的小文本文件，由 `batch/batch.json` 列出原始字节指纹。
- 该导出批次故意只含一个教学附件，没有科学记录或准入结果。业务记录的完整引用检查另有正反例测试；不能用这个批次冒充论文知识导出。

真实调用必须把占位引用替换为经固定来源和验证的精确记录，并由执行宿主产生真实运行信息；不要把整个示例直接投入生产。
