# Paper Agent 案例

同一篇论文（arXiv 2608.14798v1，稳定子统计力学）的三次运行，并列存放以便比较。
读的都是同一份源字节（压缩包 SHA-256 `3e3c04d8…`，16 个文件）。
**没有一次是科学验证**，也没有一次完成了被接受的交付。

## 按 AGENT.md 1.0 的两次运行（历史案例，不改写）

- [2608.14798v1](2608.14798v1/README.md)：真实 arXiv TeX 取源与候选提取，33 项作者主张、9 项数学目标。
  包含规范审计、未通过的完整包校验、原文定位与重放脚本。
- [2608.14798v1-claude-opus-5](2608.14798v1-claude-opus-5/README.md)：claude-opus-5 的独立运行，
  36 项作者主张、32 项数学目标、97 条字节级原文定位，共 273 条记录。附四个接口探针与两份交接 Task 校验，
  结论是单主体运行在范围冻结处必然断链。

两次独立得出同一个核心阻塞：生产者自述的对应关系无法通过自审检查，义务分母无法冻结。

1.1 新增的 `check_output.py` 对这两份旧记录的有限填写检查结果不同：前者 0 错误，
后者 67 处条件缺来源定位、3 处缺 CONCLUSION 组件。前者未被这些有限规则报错，
**不表示**其拆分、主张强度或数学目标覆盖已合格。
两份旧运行的校验脚本会把规范哈希与当前 AGENT.md 比对，升级后有意失败；1.0 原文保存在 [../history/AGENT-1.0.md](../history/AGENT-1.0.md)。

## 怎么比较

跨运行比较按**原文位置和组件含义**对齐，不按第几条 claim、运行 ID 或哈希对齐。
三次的主张条数不同主要是拆分规则不同（1.1 的 R2 要求有编号断言不合并），
**条数本身不是质量指标**，也不应互相当作对照真值。跨模型一致性在本目录**未测量**。
