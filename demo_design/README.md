# AgtXIv design prototype

A self-contained, dependency-free visual prototype for an AgtXIv landing page and registry interface.

## Preview

From the repository root:

```bash
python3 -m http.server 8000
```

Open <http://localhost:8000/demo_design/>.

The prototype uses only local HTML, CSS, JavaScript, and the copied AgtXIv logo in `assets/`. The registry workbench is a concept preview; it does not claim that every displayed verification axis is complete in the pilot.
