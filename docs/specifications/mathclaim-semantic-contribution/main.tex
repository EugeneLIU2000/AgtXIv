\begin{abstract}
This document studies how an already source-aligned and verified mathematical claim graph can reduce redundancy in views of source-faithful scientific claims without deleting information or confusing formal verification with scientific acceptance. It relates computational-linguistics research on scientific discourse, argumentation, citation intent, natural-language inference, paraphrase, document-level information extraction, and contribution modeling to the AgtXIv claim architecture. The proposal uses explicit claim--mathematics groundings, typed semantic relations, and query-relative reversible views. It represents a paper's contribution as a baseline-relative, auditable vector and partial order rather than an uncalibrated scalar score. A stratified purposive gold-slice study reuses the existing ten-paper claim corpus; it is a counterexample-oriented design test, not a population sample.
\end{abstract}
