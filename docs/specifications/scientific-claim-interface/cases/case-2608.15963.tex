\paragraph{Difficult split and scope examples.}
The exact-update passage must not normalize into an unconditional hardness theorem. Its structure is
\[
\begin{aligned}
\text{exact local preservation}
&\Longrightarrow U_{\mathrm{obf}}=U_{\mathrm{Cliff}},\\
&\quad\text{but the authors conjecture hardness only if}\\
&\qquad U_{\mathrm{obf}}\not\approx_{\substack{\text{classical}\\\text{distinguishability}}}U_{\mathrm{random}}.
\end{aligned}
\]
The source explicitly says that the Clifford unitary itself is efficiently simulable when presented as Clifford gates. Presentation, adversary access, and conjectural modality therefore belong to the claim scope.

The SSB soundness-like statement is only a baseline against an uninformed uniform sampler. With $|S_C|=2^r$ and independent uniform samples,
\[
Ns\sim\operatorname{Binomial}(N,2^{r-n}),\qquad
\mathbb E[s]=2^{r-n},\qquad
\operatorname{Var}(s)=\frac{2^{r-n}(1-2^{r-n})}{N}.
\]
It is not a theorem against every polynomial-time adversary. The record preserves ``no information about $S_C$'' as an adversary-model condition.

The numerical fit
\[
T_{\mathrm{lower}}=n(1-e^{-\lambda\epsilon})
\]
is stored as a reported model of the simulated data, not as a universal asymptotic theorem. The rigorous statement is instead the imported hierarchy
\[
\nu(U)\leq T_{\mathrm{opt}}(U)\leq T_{\mathrm{circ}}(U).
\]
Three inventory records deliberately retain bundles. The unitary-nullity record joins definitions, Clifford/non-Clifford properties, and an imported $T$-count lower bound; the peaked-circuit record joins a definition, a polynomial-sample consequence, and an open construction-hardness limitation. The affine-support record joins imported stabilizer structure with the current SSB protocol use, so its bundle-level attribution is \texttt{AMBIGUOUS} while its review note assigns each clause. Each bundle has an explicit split note and must be separated or typed relationally at accepted-claim promotion.
