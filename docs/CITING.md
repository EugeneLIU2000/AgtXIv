# Citing AgtXIv

Identify the exact repository snapshot you used. The schema v0.3 framework
currently has no tagged software release or project publication DOI recorded
in this release preparation. Do not infer either from a schema number.

A repository citation can use this form, replacing the bracketed fields:

> AgtXIv repository contributors. AgtXIv, schema v0.3 research framework.
> Git commit [full commit ID]. https://github.com/EugeneLIU2000/AgtXIv.
> Accessed [date].

Link to `https://github.com/EugeneLIU2000/AgtXIv/tree/[full commit ID]` so that
the citation identifies stable source bytes. Record the actual commit you
used, even when it differs from the published branch tip.

When discussing a research result, cite the original paper separately and
state the scope of AgtXIv's contribution: candidate extraction, graph
construction, a particular formal implication, or another evidenced result.
A repository citation cannot replace the paper citation or prove source
alignment. Name any retained run that supports your statement and disclose
whether its evidence is publicly available.

The proposed citation is a repository attribution format, not an ownership
decision, release identifier or license grant. Formal author metadata can be
added after maintainers establish it.
