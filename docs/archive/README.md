# Non-normative archive

This directory preserves superseded documents and visual drafts for provenance. Nothing here defines current AgtXIv behavior.

- `specifications/`: historical snapshots replaced by the canonical root [`AgtXIv.md`](../../AgtXIv.md).
- `diagram-drafts/`: unreferenced or superseded visual drafts retained for comparison.

Exact duplicate drafts are not archived: Git history and the archive manifest are sufficient. In particular, the former root files `AgtXIv_v1.md` and `AgtXIv_v2.md` were byte-identical (SHA-256 `4d41d1035bcf4749b6895e61dd1f52891460a17084b7667ab3e441e3f6b51c9d`); their accepted content is now the canonical [`AgtXIv.md`](../../AgtXIv.md).
