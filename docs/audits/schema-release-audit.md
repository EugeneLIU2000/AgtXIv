# Schema release audit

This is a reproducible structural inventory and a bounded interface review. It is **not** scientific acceptance, release certification, or a declaration that all planned services exist.

Primary project scope: **135 schemas**; **135** have no reported structural/document-table issues. The scan found **374 physical schema files** including copies and third-party material. It resolved **1335 primary reference occurrences** offline.

V3 review denominator: **64/64 record families**, **463 payload fields** and **95 fields in 19 shared value types** inventoried against both generated field tables. The common record envelope has **11 fields**. These counts describe review coverage, not scientific completion.

Reproduce from the repository root:

```bash
.venv/bin/python -B tools/audit_schemas.py
.venv/bin/python -B tools/audit_schemas.py --check
```

The JSON ledger contains every file, exact byte hash, dialect, reference result, field inventory, static consumer matches, maintained source and semantic-review boundary. `--check` fails when inputs or the generated reports differ. It never regenerates contracts.

## Cross-record review

| Boundary | Observed mechanism | Remaining verification |
|---|---|---|
| Exact identity and offline resolution | All supplied exact refs and artifact bytes are checked; the full record reference graph is acyclic, and input copies are detached. | An adopted bundle identity and distributable local resources are required; a hash is neither source authenticity nor authority. |
| Scope and obligation conservation | Source partition, frozen discovery equality, predecessor dispositions, current heads and typed target witnesses are implemented. | Independently complete scientific discovery, external historical-universe completeness, and unsupported stages remain explicit. |
| Joint inference and local assumptions | Premises remain joint, local contexts constrain inference/discharge, and route-level cycles/membership are checked. | Rule witness validity, route conclusion derivation and full scientific dependencies need evidence beyond graph shape. |
| Six axes and non-promotion | Method/axis matching, exact target binding, conditions, evidence outcomes and synthetic ancestry have dedicated mechanical checks. | SCH-002 was reproduced and fixed with exact formal-side checks and outcome gates; scientific semantic sufficiency remains independent. |
| Formal proof versus statement alignment | Formal-check binds toolchain/attempt/declarations/axioms separately from semantic alignment and scientific applicability. | Accept correct formal statement translation even when proof is unfinished; require actual formal-side endpoints, controlled execution and independent interpretation for corresponding claims. |
| Relations, contribution and reuse | Exact endpoints, prior-baseline membership, witnesses, comparison dimensions and conditions are retained. | Relation-kind meaning, complete endpoint coverage, evidence standards per use and real accepted/rejected reuse need deeper checks. |
| Release and admission | Manifest→audit→certificate→release and decision→snapshot→receipt ordering is acyclic; roles and candidate partitions have checks. | Generic validation is not an adopted production policy, scientific review, signature or publication command. |
| Persistence and queries | LocalStore is immutable/transactional/provisional; exact historical reads retain relevant conflict endpoints. | SCH-007 relation-only receipt suppression is fixed. Public search/API semantics, official admission, independent checkpoints and capacity evidence remain separate. |

## Interpretation and limits

- A family review identifies interface meaning, inspected enforcement and remaining work; it is not a complete proof of every semantic invariant.
- Legacy, test, generated, nested-worktree and third-party schemas are inventoried separately; no old scientific status is upgraded.
- Static consumers are exact path, URI or discriminator text matches plus explicitly reviewed group consumers; dynamic references and runtime execution are not inferred.
- All refs resolve offline within the primary group or isolated copied/third-party groups. Copies cannot satisfy a missing primary dependency.
- Symlinks and dependency/internal directories are excluded explicitly; no source generator, TeX, build, remote fetch or scientific execution is performed.
- The script validates schema syntax and references, not every dataset instance; test execution and real scientific review are separate evidence.
