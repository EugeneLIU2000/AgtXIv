日期：2026-09-08。范围：本轮发布工作与其已有证据；保持原有科学、版本和治理状态。

**首次可用网页已经发布。** [当前站点](https://agtxiv-research.dd2528575364.chatgpt.site) 采用 Sites 私有访问。它可以接受新的 arXiv 论文，真正获取来源、执行有界分析、保存任务并展示结果。白色阅读界面、交互示意、接口说明、55 页技术报告和可独立编译的完整 TeX 源码包均已交付。整个仓库的严格发布门槛和完整 V3 科学流程仍有明确的后续要求。

## 1. 回到最初想实现的效果

本项目现在更接近一份可追溯的科学工作记录：论文原文是材料，候选主张是带有原文坐标的卡片，关系图说明可能的联系，六个评估问题告诉读者还缺什么。新的论文处理确实运行，但当前运行内容是来源结构、候选片段和局部引用的提取。数学正确性、物理适用条件和独立科学认可仍要另做工作。

鲁棒性案例给出了直观理由：保持迹的自由操作把带正负号的权重重新分配，三角不等式约束绝对权重之和；要得到输入鲁棒性的结论，还必须使用最优分解。选取一个测量结果并重新归一化会改变条件，因此后选择不能直接沿用这条保迹证明。网页滑杆只演示这段代数直觉，没有假装计算某个具体量子态的鲁棒性。

| 原始要求 | 已有交付 | 必须保持的解释 |
|---|---|---|
| 检查项目，尤其所有 schema | 目录与消费者梳理；135 份主项目 schema 的逐文件结构清单；全部 64 类 V3 记录的字段及有界语义审阅；关键跨记录缺陷修复 | 自动结构检查、人工接口审阅和科学验证分别计证据；没有声称全仓每个文件都人工逐行审完 |

## 4. 还有哪些必须继续，哪些不阻挡本次网页交付

本轮核心交付已经具备。最后的交付清单必须绑定实际站点版本、线上 PDF/ZIP/API 下载，以及成功、失败、重试和持久读取证据；这些收尾记录由集成维护者完成。用户应得到一个直接可用的入口，以及能继续修改的源码和未完成事项，而不必自行猜测哪个原型有效。

若后续目标是“整个仓库的严格发布门槛通过”，仍需正式处置旧测试身份基线与新候选的关系，按要求解决 Stabilizerness 的缓存/隔离边界，并在选定最终输入上取得对应检查结果。本次没有通过覆盖旧基线或删除缓存来消除阻塞。

若后续目标是“完整科学知识系统”，仍需全文语义覆盖、独立六轴评估、可靠的源文与形式表达对齐、真实贡献与复用验证、科学准入及正式治理。这些工作继续按原 58 项标准推进。网页上线、记录格式有效或局部 Lean 构建成功，都不会自动改变它们的状态。

下一轮运维可明确公开访问范围、保留期、容量、异地备份与恢复演练。当前私有访问、同机归档和单次跨部署读取，各自只证明实际观察到的范围。到 03:00 Europe/Amsterdam 硬截止即停止本轮执行，未完成内容按[发布计划](../roadmaps/publishable-release-plan.md) 保留可接续待办。
