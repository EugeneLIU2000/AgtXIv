# V3 实验契约 0.0.0：执行状态与下一步

**更新日期：2026-09-07。状态：持续实施中，V3 整体未完成。**

本次已恢复中断的构建，核对完整英文 schema 包与中文逐字段说明，并继续实现义务成功见证、固定上游离线导入、潜在依赖影响、本地事务存储和历史查询。原 [58 项实施清单](v3-implementation-plan.md)仍是任务分母；没有把它改成“只要 schema 齐全就完成”。目前将 **P1.1、P1.2、P3.1 三项标记为本地机制完成**，其余 55 项分别保留设计、部分实现或待实施状态。新增本地存储、依赖分析及义务检查没有被等同于整阶段完成。这个数量不是项目完成百分比，各任务规模并不相同。

直觉上，当前先做成了可靠的“记录格式与核对工具”：可以保存作者说了什么、论证依赖什么、哪份检查支持哪个目标，并拒绝一批错误拼接。要成为可复用知识，仍须有人或符合政策的 agent 真正审阅原文、论证、形式对齐和科学条件，再由独立流程决定哪些条目可以入库。

## 最新 goal：真实论文候选闭环已完成（非科学闭环）

在上述恢复检查点之后，已对 robustness-of-magic 论文完成有界的真实候选流程：全目录捕获 → 全文词法候选清点 → R3 代表性论证候选 → 未完成义务/前沿 → 原子保存 → 独立进程历史查询。实际捕获 **14 文件、1,542,636 字节**；其中八个 `build/` 文件只是现场已有的本地生成物，不是本轮运行回执。主文件 **548 行**分为 240 条候选线索、204 条非主张线索、104 条未知文本；这些不是科学主张数量。

产生 **35 条 V3 候选记录和 1 条未采用的提议政策**，六个解释候选、五条显式依赖、十二个开放前沿及九项全部 `OPEN / DEFERRED` 的候选义务。既有依赖分析能从定义到达 R3，但不会到达独立的后选择推广。没有伪造 FrozenScope、科学评估、身份凭据、发布或准入；正式冻结义务校验明确 `NOT_PERFORMED`。

从空数据库导入、关闭后只读重开，以及同一已知观察时间/输入下的逐字节相同重放均已实测。新增 **62 个测试**，最终完整 V3 检查为 **710 passed，零失败/错误/跳过**；生成、离线协议/包校验、Python 编译和 **106/106** 旧固定输入字节检查通过。详见[中英使用说明](../architecture/v3-real-candidate-loop.md)、[实际候选与验证证据](../evidence/v3-real-candidate/README.md)。此前 648 项结果作为上一检查点保留，不覆盖其历史证据。

该 goal 的完成没有增加整阶段完成勾选：全文语义发现、正式独立冻结、真实形式/科学核查和正式准入仍缺。词法覆盖不能冒充全文科学完备。

## 2. 检查方式和发现的实际问题

可重复命令：

```bash
.venv/bin/python tools/generate_v3_schema_v00.py --check
.venv/bin/python tools/generate_vibefeld_protocol.py --check
.venv/bin/python tools/validate_v3.py --bundle-only
.venv/bin/python -m pytest tests/v3 -q
```

生成一致性检查覆盖全部 70 个生成文件。schema catalog 测试覆盖 64/64 对象族、19 个共享类型、封闭字段、必填项、类型与条件分支、哈希和离线引用，以及中英文的全部 569 条字段表行。每个对象族的最小样例明确标为 `SYNTHETIC`，不会假装来自真实论文。

独立代码审计先构造合法对照，再变更精确引用并重新计算相关哈希，实际找出了以下漏洞；现已修复并加入定点回归：

- 普通推理通过填写“已解除上下文”逃出局部假设。
- 源结果生产者借无关评估审阅自己的复用决定，或使用原文片段代替复用评估。
- 尚有新增条件的论证被投影成不带条件的完整支持。
- 政策要求外部身份凭据，却接受只有本地凭据的决定。
- 新范围审阅未看到旧范围，就通过失败处置删掉旧义务。
- 冻结范围漏掉标准要求的来源、清点、主张阶段，仍进入认证发布。
- 论文审计者或认证者兼任同一包的准入者。
- 入库回执借用另一决定产生的快照，声称加入了实际没有加入的对象。
- 准入 C1 却使用 C2 的评估，或审阅时完全没有看 C1。

恢复实施的独立复审又发现并修复了以下问题，均保留合法对照与拒绝回归：

- 成功论证/形式证据的承重节点虽然存在于全局集合，却不在候选包的历史截面中，仍被计作成功。
- `OBSERVED` 审阅外壳包住 `SYNTHETIC` 证明内容或反例见证；现在沿实际用于支持/记账的证据闭包检查，单纯保留的反对证据不会污染正向支持。
- 形式检查已执行但失败的 `ACCOUNT_FOR` 被误当作必须内核成功；现在与 `SUCCESS_REQUIRED` 分开，`BLOCKED` 仍不冒充实际执行。
- 上游引理提取引用不存在的节点，却获得结构导入状态。
- 明确声明的跨证明路线依赖被路线过滤器漏掉；大量见证又导致输出理由超出 schema 长度限制。
- 布尔值或浮点修订号借 Python 相等性绕过精确引用或缓存；现在在比较、建索引和缓存前检查类型。
- 只查询一条限制关系时，未展开关系两端；现在与先选端点的查询一样保留传递的相关限制关系。

三个机制组都经过修复后的独立代码复审。存储另有真实本地子进程中途退出/提交后退出的重启测试；它不是断电耐久性或生产归档认证。

这些测试检查的是程序约束是否会错误放行。独立审阅仍需要真实输入、领域判断及具体授权；没有因测试通过而填写科学认可。仓库已有全量 pytest 身份基线还包含其他未提交工作，本次未覆写它，也不把 V3 定向测试表述为全仓 `make check` 已通过。

上一轮的 **425 passed** 保留在[历史 JUnit](../evidence/v3-v0.0/contracts.junit.xml)，不覆盖为本轮结果。恢复时的实际基线是 **493 passed、2 failed**，见[恢复基线](../evidence/v3-v0.0/resume-baseline.junit.xml)：已有测试调用了不存在的 `require_authority` 参数，事件辅助函数又与 `pattern_added.name` 冲突；修复后还更正了 `LockReaped.owner` 的样例字段。中间全量运行 **624 passed** 见[中间记录](../evidence/v3-v0.0/resume-intermediate.junit.xml)，但独立复审仍发现了反例见证闭包及缓存引用类型绕过，不能只凭这一绿色结果结束。

最终修复后重新执行全部 V3 定向检查，结果为 **648 passed，0 failed，0 errors，0 skipped**，比恢复时增加 **153 个测试用例**；原有两个失败也已修复。实际输出见[最终 JUnit](../evidence/v3-v0.0/resume-final.junit.xml)，命令、包身份和 30 份实现/测试/证据文件的字节绑定见[恢复验证记录](../evidence/v3-v0.0/resume-verification.json)。70 份 V3 生成文件检查、3 份上游协议 schema/35 份源码 pin 检查、离线包校验和 Python 编译检查均通过。没有运行全仓 `make check` 或受限执行项。

本轮另行复核原始素材清单，最终 **106/106** 字节匹配，见[本次清单检查](../evidence/v3-v0.0/resume-corpus-integrity.json)。检查曾发现对已固定的接入设计文档进行维护性更新会使其 pin 失配；已撤回这两处本轮文档改动，保留固定输入原字节，当前进展写入新的[中英机制说明](../architecture/v3-local-mechanisms.md)，没有静默重算原清单。上一轮五篇论文的 32 文件静态清点仍是历史观察，详见[证据说明](../evidence/v3-v0.0/README.md)。

1. **继续 P1 的剩余政策与生产服务。** 当前处置分支、精确成功见证与承重来源检查已有本地实现；下一步补未支持的 CONTRIBUTION/RELEASE 完成阶段、完整权限政策和产生真实记录的服务，不用任意引用填补证据。
2. **把真实候选清点推进到语义范围。** robustness 的全目录和548行词法初筛已落地；下一步逐条审阅候选线索、非主张线索与未知文本，核对跨行/宏/图表遗漏及物理条件，再由符合政策的独立流程冻结真实科学分母。当前九项候选义务继续保持未完成。
3. **把 P3 离线适配推进到真实独立输入。** 固定协议、离线解析与重放已实现；下一步需要独立捕获的真实导出、科学依赖解释和受控命令/身份回执。当前不运行上游，普通 `graph.json` 仍不充当完整论证。
4. **做出有条件边界的真实交接。** 区分原文主张、系统重构和额外假设，先把科学残余和各对齐目标写全，再根据处理标准接入独立形式/科学检查。继续遵守不运行 demo 的要求。
5. **在本地事务之上接入正式政策。** 不可覆盖候选存储、并发 CAS、历史查询和相关冲突保留已实现；下一步是独立发布/准入政策、外部检查点和生产边界。复用与贡献依赖真实已有知识，不在测试生成器中伪造。
6. **用真实相关论文评估价值。** 只有在相同处理标准下获得成功复用、合理拒绝、局部修订和冲突可见性之后，才比较减少了哪些重复工作。未测量的效果继续记为未知。
