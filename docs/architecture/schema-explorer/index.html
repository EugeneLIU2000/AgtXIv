数学结构

两个前提，共同支撑一个结论

前提 A＋前提 B→InferenceStep→结论 C

premise_refs[] 是联合前提；conclusion_ref 是结论。篇内、跨篇使用同样的精确引用。

单份证明的依赖保持无环；等价关系、候选关系与反馈流程不应混进证明 DAG。

第一版验收

两篇论文，一段可检查的复用

  1. 一个 claim 能定位到原文并展开为证明步骤。
  2. 一次旧结果复用成功，一次因假设不匹配被拒绝。
  3. 保存记录后，可重读版本、检查证据和依赖关系。
